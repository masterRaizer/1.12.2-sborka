Dynamic Hand Light (dynlight) for 1.12.2, client only. Built from the pingtab RetroFuturaGradle template: copy build.gradle, settings.gradle, gradlew* and gradle/ from F:\minecraft-mods\pingtab, then gradlew build --no-daemon (JAVA_HOME = JDK 25 from ~/.gradle/jdks). Project folder: F:\minecraft-mods\dynlight.

How it works: early mixins (MixinBooter) on World.getCombinedLight and ChunkCache.getCombinedLight, client world only. The block-light part of the packed light becomes max(stored, dynamic). Light sources (held light items, dropped light items, burning entities) are collected once per client tick and only the changed render sections are remeshed. World light data is not changed, so mob spawning is not affected. No entity capabilities (that is what crashed Smooth Entity Light on the Artifacts mimic).
