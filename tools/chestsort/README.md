# chestsort

Свой мод сборки: кнопки сортировки в сундуках и инвентаре игрока.

- Две кнопки 9×9 в строке заголовка секции: «сортировать» и «критерий» (A название, M мод, # количество, C категория/ID). Shift+клик по критерию — назад. Подсказка при наведении, после клика 2.5 с подпись «Сортировка: …».
- Клиент только считает порядок, сервер сливает стаки и раскладывает (SimpleNetworkWrapper). Отмена при любом сомнении: слот не принимает предмет, нельзя взять, сумма не сходится, курсор не пуст.
- Нужен на сервере и клиенте; без мода на сервере кнопок нет (сервер шлёт hello при входе). Клиент без мода может зайти.
- Конфиг config/chestsort.cfg: вкл/выкл на сервере и клиенте, хотбар, минимум слотов, чёрные списки GUI и контейнеров, дополнительные классы слотов.
- Сборка: шаблон RetroFuturaGradle (как lootclear), JDK 25 у Gradle, `gradlew build --no-daemon`. Обёртку gradle взять из tools/... любого RFG-проекта (jar в репозиторий не кладём).
