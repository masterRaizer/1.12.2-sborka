# Измерения для сборки

> **Это памятка для ручной установки модов с CurseForge, а не задача для агента.** Целиком агенту её не отдавай. Для измерений, которые надо писать самим (раздел Б), агент получает только заполненный **Промпт 08** из [backport-prompts.md](backport-prompts.md), по одному измерению за раз.

Цель: много мест для исследования, чтобы не было скучно. Сейчас в сборке есть только **Atum 2** (Египет).

**Перед установкой проверь версию под 1.12.2 на CurseForge.** Многие моды 1.12.2 есть только там, а не на Modrinth. Ставь группами по 3–4 мода и после каждой группы делай тестовый запуск.

## Шаг 0: бюджет ID биомов (обязательно до установки)

В 1.12.2 жёсткий лимит **256 ID биомов**. `NotEnoughIDs`, который стоит в сборке, расширяет **только ID блоков**, биомы он не трогает. Если лимит переполнить, игра упадёт при загрузке.

**Сейчас занято 152 из 256** (по реестру `level.dat` мира с BoP: Biomes O' Plenty 73, ванилла 62, Atum 9, прочие 8). Свободно около 100.

Примерно сколько займут моды из списка (уточняй по факту после установки):

| Мод | Биомов (примерно) |
|---|---|
| Twilight Forest | ~20 |
| Betweenlands | ~8 |
| Erebus | ~10 |
| Aether Legacy, Midnight, Gaia, Cavern II | по 1–8 |
| Tropicraft | ~8 |
| Abyssalcraft | ~10 |
| Galacticraft + Planets | ~10 |
| Extra Planets / More Planets | **30–50+** |
| AoA / Divine RPG | **30+ / 15+** |

Вывод: основа (Twilight, Aether, Betweenlands, Erebus, Midnight, Tropicraft) влезает. Но вместе с Abyssalcraft, космосом и AoA лимит переполнится. Есть два пути:
1. **Ограничить список**, чтобы оставался запас не меньше 20 ID.
2. **Перейти с NotEnoughIDs на Roughly Enough IDs (REID)**: он расширяет и блоки, и биомы. Ставится **вместо** NEID, не вместе с ним. На существующих мирах переход проверяй **только на полной копии мира**.

После каждой группы модов проверяй реальное число: в логе ищи `biome` и `ID`, либо считай по `level.dat` нового мира. Можно попросить меня, я уже считал так один раз.

### Генераторы своих измерений
- **RFTools Dimensions**: собираешь измерение из «кусочков» (биомы, руды, небо). Бесконечное разнообразие, требует энергию RF, которая в сборке есть.
- **Mystcraft**: пишешь книги-миры с выбранными свойствами.

## Как не положить сервер

- **Память:** с 6–10 новыми измерениями подними память с 6 до **8 ГБ**. В 1.12.2 измерения выгружаются, когда в них никого нет, но генерация и моды всё равно добавляют нагрузку.
- **ID измерений:** в 1.12.2 они могут пересечься. После установки проверь лог на `dimension ID` и `already registered`, а ID задай в конфигах.
- **AoA и Divine RPG вместе не ставь:** будет перегруз и дубли прогрессии.
- **Структуры со спавнерами:** после истории с Castle Dungeons в каждом моде проверяй конфиг частоты данжей.

## Особые случаи при тестировании

- **The Betweenlands + OptiFine:** частые проблемы с рендером воды, тумана и неба, особенно при Fast Render и шейдерах. Проверки, что игра дошла до меню, мало: **зайди в само измерение**, посмотри на воду и туман, при необходимости выключи Fast Render.
- **Galacticraft:** тянет MicdoodleCore, который иногда конфликтует с LoliASM, VintageFix и OptiFine. Ставь его **отдельным прогоном**, без других новых модов в той же волне. Слетай на Луну и проверь.
- **Abyssalcraft:** перед игрой в его конфиге ограничь спавн шогготов в обычном мире и распространение порчи (Coralium/Dreadlands), иначе зараза расползётся по миру.
- **Twilight Forest, Erebus:** зайди в измерение и пролети 1–2 тысячи блоков. Смотри на фризы и каскадную генерацию в логе.

## Рекомендуемый порядок
0. Шаг 0: бюджет биомов (см. выше). Бэкап инстанса.
1. Twilight Forest, Aether Legacy. Тест с заходом в измерение. Пересчитать биомы.
2. The Betweenlands **отдельно**. Тест внутри измерения с OptiFine.
3. Erebus, The Midnight, Tropicraft. Тест. Пересчитать биомы.
4. Abyssalcraft (сначала конфиги), Gaia, Cavern II. Тест.
5. Galacticraft + Planets **отдельным прогоном**. Тест. Extra Planets только если остался бюджет биомов или уже стоит REID.
6. По желанию: AoA **или** Divine RPG (нужен REID), RFTools Dimensions.
7. Порты с новых версий через агента (Промпт 08, по одному): Blue Skies, Undergarden, Bumblezone.
