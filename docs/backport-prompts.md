# Промпты для агента Claude: бэкпорт контента с новых версий на 1.12.2

## Как пользоваться

- В папке `F:\промпты майн 1.12.2` на каждый промпт лежит готовый `.txt`, контекст в нём уже вставлен. Копируй файл целиком.
- **Один промпт за раз, по порядку.** Следующий давай только после того, как агент закончил текущий: сборка прошла, отчёт сдан, ручной чек-лист пройден.
- **Агент проверяет то, что можно проверить из консоли:** сборку, запуск сервера без окна, лог, JSON. **Проверку в игре делаешь ты** по файлу `ЧЕК-ЛИСТ ручной проверки.txt`: агент не видит экран, а такой отчёт он бы просто выдумал.
- Агент ведёт файл `docs/backport-plan.md` в репозитории мода. В разделе «Текущее состояние» записано, какие бэкпорт-моды сейчас стоят в сборке. Контекст в каждом промпте ссылается на этот раздел, поэтому после этапа 1 агент не будет опираться на удалённые моды.

## 01b — Безопасный путь: убрать Future Versions с миграцией миров

```
[КОНТЕКСТ]

ЗАДАЧА (этап 1b): убрать Future Versions так, чтобы в старых мирах ничего не пропало.
1. По таблице из 1a для КАЖДОГО блока, предмета, TileEntity и сущности futureminecraf:* выбери замену
   из Future MC или Unseen's Nether. Если замены нет, перенеси фичу в modernbackports.
   Таблицу старый id → новый id сохрани в docs/remap.md.
2. Миграция в modernbackports:
   - блоки и предметы: RegistryEvent.MissingMappings → remap на новые id;
   - TileEntity: в 1.12.2 MissingMappings их НЕ покрывает. Нужен DataFixer
     (ModFixs + IFixableData для FixTypes.CHUNK / BLOCK_ENTITY), который переписывает строковый id
     TileEntity в NBT чанка и конвертирует формат его данных (инвентарь бочки, мёд улья, предметы
     в костре и печах) в формат нового мода;
   - сущности: DataFixer для FixTypes.ENTITY и CHUNK (сущности внутри чанков), который переписывает id
     и конвертирует поля NBT;
   - предметы в инвентарях: id в NBT ItemStack (сундуки, инвентарь игрока, рюкзаки) обрабатывает
     MissingMappings. Проверь, что это работает и для вложенных инвентарей.
3. Конфиги: выключи дубли между Future MC и Unseen's Nether (оставь по одной реализации)
   и пропиши OreDictionary, чтобы рецепты принимали любой вариант материала.
4. Проверка (консоль): создай тестовый мир на сервере со старыми модами, расставь через команды
   /setblock и /summon по экземпляру каждого блока, TileEntity с содержимым и моба, сохрани и
   останови. Затем убери Future Versions, добавь modernbackports, запусти сервер и проверь
   через NBT-дамп чанков (скриптом), что все id переписаны, а содержимое на месте.
5. Обнови «Текущее состояние» в docs/backport-plan.md.
ОБЯЗАТЕЛЬНО: в отчёте напиши, что перед заменой мне нужно сделать полный бэкап миров.
```
