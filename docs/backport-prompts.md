```

ЗАДАЧА (этап 1): в сборке три мода дублируют друг друга: Future MC 0.2.21, Future Versions 1.3.1
и Unseen's Nether Backport 0.7. Незерит есть во всех трёх, колокол, бочка, костёр, пчёлы и многое
другое в двух. Получается три разных незеритовых слитка, дубли рецептов и лишняя нагрузка.
Нужно собрать всё в один мод modernbackports, а эти три убрать.

1. Распакуй все три jar (лежат в minecraft/mods сборки, имена в MODS.md) и составь таблицу:
   фича → какие моды её дают → чья реализация лучше (полнота, баги, производительность).
   Мобов (пчёлы, панда, пиглины, хоглины, страйдеры, зоглины и т. д.) и предметы сравни особенно тщательно.
2. Проверь лицензии всех трёх. Код можно переносить только из модов с открытой лицензией,
   с указанием авторства. Если лицензия закрытая или не указана, перепиши фичу сам по ванильной логике,
   не копируя их код.
3. Перенеси в modernbackports ВСЁ из трёх модов по одной реализации на фичу. Ничего не потеряй:
   в конце сверь со списком из пункта 1, что каждая строка закрыта.
4. СОВМЕСТИМОСТЬ СО СТАРЫМИ МИРАМИ (обязательно): в мирах уже лежат блоки и предметы с id
   futuremc:*, futureversions:* (уточни реальные modid в mcmod.info) и id Unseen's Nether.
   Через RegistryEvent.MissingMappings переназначь КАЖДЫЙ старый id на наш новый, чтобы после
   удаления трёх модов предметы в сундуках и блоки в мире не пропали. Также переназначь сущности
   (мобов). Сделай таблицу старый id → новый id в docs/remap.md.
5. Конфиг: каждая фича выключается отдельно (например, если Quark уже даёт что-то похожее).
6. Проверка: создай мир со старыми тремя модами, поставь по блоку каждого вида, положи в сундук
   по предмету, заспавни мобов, сохрани. Потом замени три мода на modernbackports, загрузи мир
   и проверь, что всё на месте.
```
